## 4. 当前已验证状态

### 4.1 XNU/GPU 基线

p538（无 fastboot 参数）曾进入 XNU 并显示：

    NU735 gdsc mode=1
    gcc=0x1/0x1
    cx=0x22f001/0x22f001
    gx=0x22f801/0x22f801
    hw=0x2a00010a
    ahb=0x0/0x0
    cgmu=0x80002001
    hub=0x80000001

结论：

- gfx.lvl + mxc.lvl ARC vote 成功；
- GDSC CX/GX 软件写不进去；
- AHB 仍为 0；
- cx.lvl 在 AOP 资源表中不存在；
- mmcx.lvl 单投白屏；
- UEFI 裸写 GDSC 黑屏。

### 4.2 Fastboot

p539（fastbootdebug=1）曾出现 DARWINBOOT Fastboot UI，主机枚举：

    fastboot devices -> bf7c781b fastboot
    getvar product  -> peridot

最新 Fastboot UI 仍反复打印：

    usb rx queue failed: Not Ready

主机命令无法稳定进入 FastbootCommand；根因在 FastbootUsbRead 的 OUT transfer 没有重新挂起/重试。

### 4.3 内存

main 已做静态修正：

    dram_size          = 0x80000000
    owned_memory_size  = 0x80000000 (2 GiB)
    pram               = 0xe6440000 + 0x400000

原因：

- DTS 只声明 0x80000000 + 2 GiB；
- 旧 owned 4 GiB 超出窗口；
- 旧 pram 0xa7000000 与 UEFI_FD 0xa7100000 + 0x300000 重叠。

wip/ufs-smmu 仍是旧值：

    owned_memory_size = 0x100000000
    pram              = 0xa7000000

所以 wip 当前不能打包或刷写。
